# Tindahan POS & Inventory (Sari-Sari Store & Bigasan)

A mobile-first, **100% offline / local-only** Point of Sale (POS), Stock Inventory, dedicated Rice (Bigasan) module, and Sales/Restock Logs app.

## Modules (Bottom Navigation)
1. **POS (Sari-Sari):** Fast tap-to-add grid for sari-sari items with search, category filters, cart, and Peso bill sukli calculator.
2. **Stock (Sari-Sari):** Track sari-sari quantities, low-stock alerts, quick restocking (`+6`, `+10`, `+12`, `+24`), and add/edit items.
3. **Rice (Bigasan):** Dedicated rice module with its own **Sell Rice (POS)** (quick weight buttons from `¼ kg` to `25 kg / 1 sack` or custom kg) and **Rice Stock** (shows kilos & sacks, `+25 kg / 1 sack` restock).
4. **Logs:** View **Today**, **Weekly (Last 7 Days)**, and **Monthly** sales & restock logs with automatic totals, Sari-Sari vs. Rice breakdown, total rice kilos sold, and **Undo/Void** for sales.

## Run Locally
```bash
npm install
npm run dev
```
